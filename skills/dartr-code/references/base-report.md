gl.report.contamination(x, rare.freq = 0.02, min.n = 5, z.flag = 3, min.excess = 0.02, rare.min.excess = 0.005, min.share = 20, share.tol = 0.05, depth.ratio = 1.5, depth.flat = 1.25, min.reads = 20, balance.cut = 0.25, min.calls = 1000, plate = NULL, plot.display = TRUE, plot.theme = theme_dartR(), plot.colors = NULL, plot.colors.pop = gl.colors("dis", verbose = 0), plot.dir = NULL, plot.file = NULL, verbose = NULL, ...)

- `x`: Name of the genlight object containing the SNP data [required].
- `rare.freq`: Allele frequency in the rest of the population below which an allele counts as rare; must lie in (0, 0.5) [default 0.02].
- `min.n`: Minimum number of other individuals in the population called at a locus for that locus to enter the rare-allele burden; at least 2 [default 5].
- `z.flag`: Robust z-score above which a statistic is an outlier [default 3].
- `min.excess`: Absolute amount by which heterozygosity must also exceed the population median to be flagged; a robust z-score alone over-flags populations whose members are nearly identical [default 0.02].
- `rare.min.excess`: The same absolute margin for the rare-allele burden, which is an order of magnitude smaller than heterozygosity [default 0.005].
- `min.share`: Minimum number of rare-allele loci an individual needs before its source is chosen by allele sharing rather than by residual kinship alone [default 20].
- `share.tol`: Sharing scores within this distance of the best are treated as ties and separated by residual kinship [default 0.05].
- `depth.ratio`: Foreign-allele rate in the deepest quartile of loci over the shallowest at or above which, with trend p below 0.01, the pattern is "dose" [default 1.5].
- `depth.flat`: The same ratio below which the pattern is "flat" [default 1.25].
- `min.reads`: Minimum number of reads (REF plus ALT) for a genotype to enter the read-balance test [default 20].
- `balance.cut`: Share of the reads below which the minority allele of a heterozygous call marks it as skewed; must lie in (0, 0.5] [default 0.25].
- `min.calls`: Minimum number of genotypes with at least min.reads reads for an individual to be screened by read balance [default 1000].
- `plate`: Data frame with columns id, plate and well (for example "C4", in either case) giving plate positions; overrides positions found in the individual metadata. Without it, positions come from plate_location in @other$ind.metrics, keyed by service when that column…
- `plot.colors.pop`: A color palette for the plate map, or a vector with as many colors as there are populations [default gl.colors("dis")].
- `...`: Parameters passed to function ggsave, such as width and height, when the ggplot is to be saved.
- **Returns:** A list with three elements: ind, a data frame with one row per individual holding the tier 1 and tier 2 statistics (including n.foreign, the number of rare-allele loci, and share, the partner's sharing score), the tier 3 columns foreign.rate, depth.ratio, depth.p and pattern, the tier 4 columns read.calls, skew.rate, …
