### gl.report.errorrate

Estimates the genotyping error rate from replicated individuals

```r

```
- `x`: Name of the genlight object containing the SNP data [required].
- `pairs`: A data frame with two columns giving the replicate pairs, as individual names or row indices of x. Use either pairs or replicates [default NULL].
- `replicates`: A vector with one entry per individual in x giving its replicate group (e.g. the sample ID shared by all replicates of one individual). All pairs within each group are compared; individuals with NA, and groups with one member, are ignored [default NULL].
- `min.loci`: Minimum number of SNPs genotyped in both samples of a pair for the pair to be used [default 100].
